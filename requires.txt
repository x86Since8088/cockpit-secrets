# TEST ONLY - and keepassxc-full most of all

#   *** keepassxc-full MUST NEVER BECOME A RUNTIME DEPENDENCY. ***
#
# keepassxc-cli is here as an INTEROP ORACLE: files we write must open in it and
# files it writes must open in ours (docs/KNOWN_ISSUES.md I19 - a reader and a
# writer that share a bug round-trip perfectly and interoperate with nothing).
# It is not the engine, and driving it would mean either a pty or piping the
# master passphrase into a child process on every operation and screen-scraping
# human-formatted output - a process boundary the secret would have to cross for
# no gain over an in-process library (docs/UPSTREAM-REVIEW.md 2.2).
#
# If you ever find `keepassxc-cli` in a runtime code path, that is a bug, not an
# optimisation. The test suite greps for it.
#
